# Model attribution

`yingxian-pagoda.glb` is derived from the web delivery model `yingxian-v20.glb` from:

https://github.com/huangbai-AI/yingxian-pagoda

Upstream describes it as an educational / popular-science reconstruction of
佛宫寺释迦塔（应县木塔）, not a surveyed heritage scan.

This repo recompresses the file for faster Pages loads: textures resized /
WebP-encoded and Draco re-quantized (geometry stays high detail).

Wood textures in the upstream project cite Poly Haven Rough Wood (CC0).
See upstream `使用说明.md` / README for materials notes.
