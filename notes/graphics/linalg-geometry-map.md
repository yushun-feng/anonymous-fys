交互：[变换沙箱 `#/transform`](#/transform) · 基础：[第 2 章 向量与变换](./foundation/ch02-vectors-transforms.md)

> 任广千、谢聪、胡翠芳，《**线性代数的几何意义**》，西安电子科技大学出版社，ISBN `978-7-5606-3454-8`。  
> 本书按工科线代大纲把概念串成几何/物理图像，图多，适合和沙箱对照着翻。

## 为什么要「几何意义」

代数符号算得快，但图形/引擎里真正要的是直觉：

- 这个矩阵把空间**怎么扭**？
- 乘在左边还是右边，对应**世界系还是物体系**？
- 行列式为负，意味着什么？

下面按主题给**自己的话**概括，并标明本站哪里能动手验。

## 主题 → 直觉 → 本站

| 主题 | 一句话几何直觉 | 本站 |
|------|----------------|------|
| 向量 | 有方向的量；自由向量可平移 | ch02 |
| 内积 | \(\mathbf{a}\cdot\mathbf{b}\)：投影、夹角、同向/反向 | ch02 |
| 叉积 | \(\mathbf{a}\times\mathbf{b}\)：垂直两者；三维有向面积相关 | ch02 |
| 线性变换 | 保直线、保原点；可用矩阵描述 | 沙箱里的 \(R,S\)（仿射再加 \(T\)） |
| 矩阵×向量 | 列向量约定下 \(M\mathbf{p}\)；列 = 基向量的像 | 沙箱矩阵表 + 飞镖局部轴 |
| **左乘 / 右乘** | \(A M\)：世界系再变；\(M A\)：物体系再变 | **沙箱主菜** |
| 行列式 | 有向面积/体积缩放；\(0\) 压扁降维；负号翻面 | 沙箱显示 \(\det\) |
| 基与坐标 | 同一点换基 → 数字变、几何不变 | 导读；后续可加基变换演示 |
| 特征值/向量 | 变换后方向不变（可反向），只伸缩 | 规划中；书中专章很直观 |
| 正交矩阵 | 保长度与角度（旋转/反射） | 纯旋转时 \(\lvert\det\rvert=1\) |
| 平移 | 需齐次 \(4\times4\)；对 \(w=0\) 方向不平移 | ch02 + 沙箱 \(T\) |

## 和变换沙箱怎么对读

1. 打开 `#/transform`，约定与 ch02 相同：**列向量、\(p'=Mp\)**。
2. 用剧本「歪尖端 → 对比平移」体会书里强调的**左右乘不同**（世界轴 vs 自身轴）。
3. 拧非均匀缩放，看右侧 **\(\det\)**：体积缩放如何变；反射/奇数个负缩放会让 \(\det\) 变负（朝向翻转）。
4. 再翻纸书对应章节（矩阵乘法、行列式、旋转变换），用沙箱当「动态插图」。

## 小结

- 线代在图形里首先是**空间怎么动**，不是符号游戏。
- 左乘/右乘、行列式、基的像，是最值得先建立肌肉记忆的三块。
- 纸书《线性代数的几何意义》作深度图解；本站笔记 + `#/transform` 作可交互对照。
