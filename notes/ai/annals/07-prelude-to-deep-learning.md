# 本纪 · 深度学习前夜（2006-2012）

## 这一段在争什么

CUDA、ImageNet、大规模 GPU 训练把数据与算力就位；缺一次不可忽视的公开胜利。

**怎么读**：把 Siri/Watson/Google Brain 看成入口铺垫，而不仅是产品花絮。 交互浏览见 [`#/ai`](#/ai)；总路线见 [00-roadmap](../00-roadmap.md)。

## 本时代事件（10）

| 时间 | 类型 | 事件 | 深读 |
|------|------|------|------|
| 2007 | ● 产品 | 英伟达发布 CUDA，把 GPU 通用计算工具化，为深度学习铺路 | [上游](https://zsjunai.github.io/history-of-ai/houses/nvidia/) |
| 2009 | ★ 论文 | 李飞飞（Fei-Fei Li）团队发布 ImageNet 数据集，1400 万张手工标注图片，为深度学习革命埋下种子 | [上游](https://zsjunai.github.io/history-of-ai/biographies/fei-fei-li/) |
| 2009 | ● 论文 | 吴恩达（Ng）与 Raina 发表《Large-scale Deep Unsupervised Learning Using GPUs》，证明 GPU 训练神经网络的巨大优势 | [上游](https://zsjunai.github.io/history-of-ai/biographies/andrew-ng/) |
| 2010 | · 产品 | 微软发布 Kinect，将深度感知与人体姿态识别带入消费市场 | [上游](https://zsjunai.github.io/history-of-ai/houses/microsoft-research/) |
| 2011-2月 | ● 事件 | IBM Watson 在 Jeopardy! 中击败人类冠军，认知计算概念进入大众视野 | [上游](https://zsjunai.github.io/history-of-ai/houses/ibm-research/) |
| 2011-10月 | ● 产品 | 苹果发布 Siri，AI 走进数亿人的口袋 | [上游](https://zsjunai.github.io/history-of-ai/houses/apple-intelligence/) |
| 2011 | · 机构 | 吴恩达与 Daphne Koller 共同创立 Coursera，把斯坦福机器学习课带向全球 | [上游](https://zsjunai.github.io/history-of-ai/biographies/andrew-ng/) |
| 2011 | ● 机构 | Google Brain 项目在 X 实验室秘密启动，由吴恩达与 Jeff Dean 牵头 | [上游](https://zsjunai.github.io/history-of-ai/houses/google-brain/) |
| 2012-6月 | ● 事件 | Google Brain 团队用 16,000 个 CPU 核心训练神经网络，自动从 YouTube 视频中识别出"猫" | [上游](https://zsjunai.github.io/history-of-ai/houses/google-brain/) |
| 2012 | · 机构 | 蒙特利尔大学的 Yoshua Bengio 等推动 MILA 实验室扩张，深度学习"加拿大三巨头"格局成型 | [上游](https://zsjunai.github.io/history-of-ai/houses/mila/) |
