# HelloGitHub 第 127 期摘录（2026-10）

> **出处**：[HelloGitHub 第 127 期](https://hellogithub.com/periodical/volume/127) · [GitHub 仓库](https://github.com/521xueweihan/HelloGitHub)  
> **说明**：下文为个人中文消化笔记，**不是**月刊原文转载；项目简介已改写，详情以仓库与原文为准。

本期印象：大量条目在强调**本地、低依赖、可自托管**——从无 GPU 的 MoE 推理，到浏览器内 GIS / 工具箱，再到终端玩具与 Agent 技能。

## 本期挑 8 个

| 项目 | 为何值得一看 | 仓库 |
|------|--------------|------|
| **colibri** | 纯 C 的 MoE 推理引擎：专家权重按需从盘读入，宣称约 8GB 内存、无 GPU 也能跑开源大模型，并兼容常见 Chat API | [JustVugg/colibri](https://github.com/JustVugg/colibri) |
| **cbirds** | 终端盲文点阵 + Boids 鸟群：算法演示做成屏保级玩具，适合周末摸鱼学群体行为 | [clainstone/cbirds](https://github.com/clainstone/cbirds) |
| **DEsk** | Wayland 桌面把「房间」渲成书桌，窗口像纸张折叠/揉团——交互隐喻极强的实验桌面 | [fyzugx/DEsk](https://github.com/fyzugx/DEsk) |
| **EditHere** | 截图批注 → 结构化 JSON，专给 AI 编程助手「指哪改哪」；本地 OCR/长截图，适合改 UI | [Inginnng/EditHere](https://github.com/Inginnng/EditHere) |
| **magpie** | 本地网关统一多家模型协议，让 Claude Code / Codex 等换模型或共享订阅额度 | [yetone/magpie](https://github.com/yetone/magpie) |
| **GeoLibre** | 浏览器 WASM GIS：上千分析工具、数据不出本机，还有月球/火星底图可玩 | [opengeos/GeoLibre](https://github.com/opengeos/GeoLibre) |
| **omni-tools** | 自托管全能小工具站（图/视频/PDF/JSON…），处理走本地浏览器，少把文件丢到随机在线站 | [iib0011/omni-tools](https://github.com/iib0011/omni-tools) |
| **OpenShell** | NVIDIA 开源的 Agent 沙箱运行时：按策略限制文件/syscall/网络，凭据只在批准出口注入 | [NVIDIA/OpenShell](https://github.com/NVIDIA/OpenShell) |

## 顺手记下

- **puter**：浏览器里的「云电脑」桌面，顺带提供存储 / Worker 能力，适合想体验 Web OS 原型的人 → [HeyPuter/puter](https://github.com/HeyPuter/puter)
- **miniserve**：单二进制 HTTP 甩文件，带认证、上传、扫码——临时分享比搭完整网盘轻 → [svenstaro/miniserve](https://github.com/svenstaro/miniserve)
