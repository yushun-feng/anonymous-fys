# HelloGitHub 第 124 期摘录（2026-07）

> **出处**：[HelloGitHub 第 124 期](https://hellogithub.com/periodical/volume/124) · [GitHub 仓库](https://github.com/521xueweihan/HelloGitHub)  
> **说明**：中文摘录笔记；含开源书与引擎类条目，便于以后按主题回看。

本期亮点跨度大：从复古 PC / 物理引擎，到本地语法检查与多智能体编排，还有两本可读的开源中文书。

## 本期挑 8 个

| 项目 | 为何值得一看 | 仓库 |
|------|--------------|------|
| **86Box** | 可拼硬件的复古 PC 模拟器：DOS / Win98 / XP 时代软件考古友好 | [86Box/86Box](https://github.com/86Box/86Box) |
| **JoltPhysics** | 游戏级刚体与连续碰撞库（多核、可确定性）；多款 3A 选用，学物理引擎可对照 | [jrouwe/JoltPhysics](https://github.com/jrouwe/JoltPhysics) |
| **kage** | 整站离线打包（本地文件夹 / `.zim` / 可执行包），做资料镜像或断网阅读 | [tamnd/kage](https://github.com/tamnd/kage) |
| **jabref** | BibTeX 原生文献管理：检索、去重、与 Word/LaTeX 联动，写论文实用 | [JabRef/jabref](https://github.com/JabRef/jabref) |
| **git-filter-repo** | 比 `filter-branch` 更现代的历史重写：拆仓、清密钥、批量改提交信息 | [newren/git-filter-repo](https://github.com/newren/git-filter-repo) |
| **harper** | 本地优先英文语法检查（可 WASM），不必把草稿丢上云 | [Automattic/harper](https://github.com/Automattic/harper) |
| **outlines** | 生成期约束 LLM 输出结构（类型/JSON schema），少靠事后正则修补 | [dottxt-ai/outlines](https://github.com/dottxt-ai/outlines) |
| **ai-agent-book** | 开源中文书《深入理解 AI Agent》：上下文、工具、MCP、Coding Agent + 实验 | [bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book) |

## 顺手记下

- **simplewall**：基于 WFP 的精简 Windows 网络管控（独立于系统防火墙 UI）→ [henrypp/simplewall](https://github.com/henrypp/simplewall)
- **little-book-rl**：《强化学习小册子》，从概念到 PyTorch 实现 → [alxndrTL/little-book-rl](https://github.com/alxndrTL/little-book-rl)
- **gastown**：多 AI 编程助手并行编排，Git 持久状态 + 合并队列 → [gastownhall/gastown](https://github.com/gastownhall/gastown)
