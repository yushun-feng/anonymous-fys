# HelloGitHub 第 125 期摘录（2026-08）

> **出处**：[HelloGitHub 第 125 期](https://hellogithub.com/periodical/volume/125) · [GitHub 仓库](https://github.com/521xueweihan/HelloGitHub)  
> **说明**：原创中文消化；项目评价是个人视角，细节以仓库 README 为准。

本期关键词偏**开发环境 / 低显存推理 / 可定制桌面播放器**，也有不少「把书或计划喂给 Agent」的技能向工具。

## 本期挑 8 个

| 项目 | 为何值得一看 | 仓库 |
|------|--------------|------|
| **RetroArch** | libretro 官方前端：一套 UI 挂多核心，着色器/即时存档/录制齐全，复古游戏一站式 | [libretro/RetroArch](https://github.com/libretro/RetroArch) |
| **EUI-NEO** | 无 WebView 的轻量 C++ 声明式 UI（GLFW/SDL + OpenGL/Vulkan），想避开 Electron 可看 | [sudoevolve/EUI-NEO](https://github.com/sudoevolve/EUI-NEO) |
| **fooyin** | 空白画布式桌面播放器：布局、插件、脚本都能折腾，音乐党可当「可塑 Winamp」 | [fooyin/fooyin](https://github.com/fooyin/fooyin) |
| **dbmate** | 纯 SQL 迁移、不绑 ORM 语言；多库支持，团队 schema 同步很干净 | [amacneil/dbmate](https://github.com/amacneil/dbmate) |
| **devpod** | 按 DevContainer 标准拉本地/远程/K8s 开发环境，闲置关机与预构建省钱 | [loft-sh/devpod](https://github.com/loft-sh/devpod) |
| **gpu.js** | 把简单 JS 函数编译成 shader，在浏览器里做 GPGPU——和站内 GPU/Shader 兴趣相邻 | [gpujs/gpu.js](https://github.com/gpujs/gpu.js) |
| **airllm** | 分层加载换显存：号称 ~4GB 显存可推 70B 级模型（以官方说明为准），低配本可试用 | [lyogavin/airllm](https://github.com/lyogavin/airllm) |
| **deepseek-harness** | DeepSeek 官方 Agent 框架：模型适配、工具、会话循环皆插件化，带 Web UI | [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) |

## 顺手记下

- **LinearAbiltyCastingThreeJS**：程序化技能特效沙盒（冰霜/闪电/陨石…），学 GLSL 粒子很直观 → [achrefelouafi/LinearAbiltyCastingThreeJS](https://github.com/achrefelouafi/LinearAbiltyCastingThreeJS)
- **plannotator**：Agent 出计划/diff 后自动开浏览器批注，反馈回传执行 → [backnotprop/plannotator](https://github.com/backnotprop/plannotator)
- **WindInput**：Rust 轻量中文输入法（五笔/拼音等）→ [huanfeng/WindInput](https://github.com/huanfeng/WindInput)
