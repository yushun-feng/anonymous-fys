# HelloGitHub 第 126 期摘录（2026-09）

> **出处**：[HelloGitHub 第 126 期](https://hellogithub.com/periodical/volume/126) · [GitHub 仓库](https://github.com/521xueweihan/HelloGitHub)  
> **说明**：个人中文摘录，非月刊原文；链接直达上游仓库。

本期里和本站兴趣重叠较多的是**图形/纹理工具**、**开发者日常 CLI**，以及一批「AI 编程助手旁路」技能与编排工具。

## 本期挑 8 个

| 项目 | 为何值得一看 | 仓库 |
|------|--------------|------|
| **armorpaint** | 拖模型就能刷 PBR 纹理，节点 + UV，支持 glTF/FBX 等——和站内 graphics 路线很搭 | [armory3d/armorpaint](https://github.com/armory3d/armorpaint) |
| **flameshot** | 跨平台截图标注「常青树」：箭头/马赛克/延时/上传，Linux 桌面尤其好用 | [flameshot-org/flameshot](https://github.com/flameshot-org/flameshot) |
| **hey** | 迷你 HTTP 压测：并发、耗时分布、HTTP/2，比拉一整套 k6 更轻 | [rakyll/hey](https://github.com/rakyll/hey) |
| **PMail** | 小体积自建域名邮箱（SMTP/POP3/IMAP + Web），想玩邮件协议可对照站内协议探索 | [Jinnrry/PMail](https://github.com/Jinnrry/PMail) |
| **microlighter** | 用 CSS Highlight API 做代码高亮，DOM 不塞 span，体积约 2KB | [davatron5000/microlighter](https://github.com/davatron5000/microlighter) |
| **broot** | `tree`/`ls` 的终端升级版：模糊跳转、预览、多面板，大型仓库浏览更顺 | [Canop/broot](https://github.com/Canop/broot) |
| **numbat** | 带物理单位的科学计算器（还能当小语言用），单位换算不必另开网页 | [sharkdp/numbat](https://github.com/sharkdp/numbat) |
| **threejs-architecture-effects** | Agent Skill：生成「逐层搭建」的 Three.js 中式古建页面——和木塔展台同属 3D 氛围向 | [lhlGitHub/threejs-architecture-effects](https://github.com/lhlGitHub/threejs-architecture-effects) |

## 顺手记下

- **QuickLook**：Windows 空格键快速预览，类 macOS 体验 → [QL-Win/QuickLook](https://github.com/QL-Win/QuickLook)
