# 第 0 章：入门与工具链

> 来源：[learncpp.cn](https://learncpp.cn/) 第 0 章（Introduction / Getting Started）

## 小节地图

0.1–0.4 教程与开发流程 → 0.5 编译/链接/库 → 0.6–0.7 IDE 与首个程序 → 0.8 常见问题 → 0.9–0.13 构建配置、扩展、警告、语言标准。

## 要点

- C++ 典型流程：**编辑 → 编译 → 链接 → 运行**；库在链接阶段参与。
- 优先装现代 IDE/工具链，并显式选择语言标准（如 C++17/20），关闭会掩盖错误的编译器扩展。
- Debug / Release 配置用途不同：调试用符号与较少优化，发布用优化。
- 把警告级别调高；把警告当错误处理可尽早暴露问题。

## 易错点

- 只“能编译通过”却未确认实际标准（扩展默认开启时行为会偏）。
- 混用多个编译器/工具链却不统一标准与警告设置。
- 把链接错误当成语法错误；缺库或缺目标文件时看链接器信息。

## 自检

能独立创建项目、编译运行 Hello World，并说明当前编译器用的语言标准。
