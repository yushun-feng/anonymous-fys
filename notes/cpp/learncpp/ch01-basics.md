# 第 1 章：C++ 基础

> 来源：[learncpp.cn](https://learncpp.cn/) 第 1 章

## 小节地图

语句与结构、注释、对象与变量、赋值/初始化、`cout`/`cin`/`endl`、未初始化与 UB、关键字与命名、空白格式、字面量与运算符、表达式、首个小程序、章末测验。

## 要点

- 程序由**语句**组成；表达式计算出值，语句完成动作。
- **初始化优于事后赋值**；列表初始化有助于挡住收窄转换。
- `std::cin` / `std::cout` 在 `<iostream>`；优先 `'\n'`，需要刷新时再考虑 `std::endl`。
- 未初始化的自动存储变量读起来是**未定义行为（UB）**。

## 易错点

- 使用未初始化变量却“有时碰巧正确”。
- 标识符命名含糊或与关键字冲突；忽略一致的命名风格。
- 把 `=` 初始化与赋值混为一谈，读代码时误判对象是否已有值。

```cpp
int x{5};      // 直接初始化意图清晰
int y = 5;     // 拷贝初始化（对基本类型通常等价）
// int z; std::cout << z;  // 危险：未初始化
```
