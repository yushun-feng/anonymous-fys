## 核心概念

### 语句、表达式与程序骨架

- **语句（statement）**是 C++ 中「做一件事」的基本单位，多数以分号结束。
- **表达式（expression）**计算后得到一个值（或产生副作用）；后面加分号就变成表达式语句。
- 可执行程序至少需要一个 `main` 函数；操作系统调用 `main` 作为入口。

```cpp
int main()
{
    int x = 2 + 3;  // 声明语句 + 初始化；2+3 是表达式
    x = x * 2;      // 赋值表达式语句
    return 0;       // return 语句
}
```

花括号 `{ ... }` 构成**复合语句（块）**，引入作用域；块里定义的变量出了块就不能再用（细节见第 2、7 章）。

### 注释

| 形式 | 用法 |
|------|------|
| `//` 到行末 | 单行注释，现代代码最常用 |
| `/* ... */` | 块注释，不可嵌套 |

注释应解释**意图与不变量**，而不是复述代码字面意思。过期注释比没有注释更危险。

### 变量、对象与值

- **对象**：一块存储，具有类型与生命周期，里面放着**值**。
- **变量**：有名字的对象（通过标识符指代）。
- **定义**通常既声明名字又分配存储（对普通局部变量而言）。

类型决定：占多少内存、能做什么运算、值如何解释。本章多用 `int`；完整基本类型见 [第 4 章](./ch04-fundamental-types.md)。

### 初始化 vs 赋值

| 概念 | 含义 | 例子 |
|------|------|------|
| 初始化 | 定义对象时立刻给出初始值 | `int x = 5;` |
| 赋值 | 对象已经存在，事后改写其值 | `x = 7;` |

推荐**定义时就初始化**，避免稍后遗忘赋值。现代 C++ 常见三种初始化写法：

```cpp
int a = 5;    // 拷贝初始化（copy initialization）
int b(5);     // 直接初始化（direct initialization）
int c{5};     // 列表初始化 / 花括号初始化（brace initialization）
int d{};      // 值初始化：对 int 即 0
```

花括号初始化在许多场景更安全：对内建类型，**收窄转换**（如 `int x{3.5};`）会被拒绝，而 `int x = 3.5;` 往往默默截断。LearnCpp 倾向在合适处推广 `{}` 初始化。

### 输入与输出：iostream

```cpp
#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;
    std::cout << "You entered " << x << '\n';
}
```

| 名称 | 角色 |
|------|------|
| `std::cout` | 标准输出流 |
| `std::cin` | 标准输入流 |
| `operator<<` | 插入运算符（输出） |
| `operator>>` | 抽取运算符（输入） |
| `'\n'` | 换行字符 |
| `std::endl` | 换行并**刷新**缓冲区 |

学习阶段优先用 `'\n'`；频繁 `endl` 可能不必要地刷新，影响性能（小程序无感，习惯宜早养成）。

链式写法合法：`std::cout << a << ' ' << b << '\n';`，因为 `<<` 返回流的引用。

### 未定义行为（Undefined Behavior, UB）

若局部 `int` **未初始化**就被读取，程序落入 UB：可能看起来像随机数、可能是 0、可能被优化掉、也可能崩溃。编译器**不保证**诊断。

```cpp
int main()
{
    int x;                 // 未初始化（自动存储期）
    std::cout << x;        // 读 x → UB
}
```

对策：定义时初始化；打开高警告（见 [第 0 章](./ch00-getting-started.md)）；用调试器看「读之前是否写过」（[第 3 章](./ch03-debugging.md)）。

UB 还包括：有符号溢出、越界访问、解引用无效指针等——后面章节会反复出现。**不要拿「在我机器上跑通」证明没有 UB。**

### 关键字、标识符与命名

- **关键字**（`int`、`return`、`if` 等）是语言保留，不能当变量名。
- 标识符：以字母或 `_` 开头，后接字母、数字、`_`；区分大小写。
- 约定（常见风格）：变量与函数用小写蛇形或小驼峰；避免无意义单字母泛滥（循环下标除外）；不要用前导双下划线或 `_`+大写（实现保留）。

### 字面量

字面量是源码中直接写出的常数值：

| 字面量 | 典型类型 |
|--------|----------|
| `42` | `int` |
| `42L` / `42LL` | `long` / `long long` |
| `3.14` | `double` |
| `3.14f` | `float` |
| `'A'` | `char` |
| `"hi"` | 字符串字面量（`const char[]`） |
| `true` / `false` | `bool` |

后缀改变类型；细节与进制写法见 [第 5 章](./ch05-constants-strings.md)。

### 表达式与运算符入门

算术：`+ - * / %`（`%` 为整数取余）。注意整数除法截断：`5 / 2 == 2`。

关系与逻辑、自增副作用等在第 6 章展开；本章只需会写简单算术与 I/O 表达式，并知道**运算符有优先级**——拿不准就加括号。

## 语法与 API

### 变量定义模板

```cpp
type_name identifier { optional_initializer };
```

### 常用 iostream 模式

```cpp
std::cout << expr;           // 输出
std::cin >> var;             // 读入到已存在变量
std::cin >> a >> b;          // 连续抽取
```

输入失败（非数字喂给 `int`）时，流会进入错误状态——完整处理见第 9 章；现在先保证测验输入合法。

### `main` 的返回值

```cpp
int main() { return 0; }           // 显式成功
int main() { /* ... */ }           // 允许省略 return 0
```

非 `0` 常表示失败；与操作系统约定相关。

## 示例

### 示例 1：注释与基本输出

```cpp
#include <iostream>

int main()
{
    // 向标准输出打印一行
    std::cout << "C++ basics\n";
    return 0;
}
```

### 示例 2：初始化与赋值对比

```cpp
#include <iostream>

int main()
{
    int x{0};          // 初始化
    x = 10;            // 赋值
    int y = x;         // 用 x 的值初始化 y
    y = y + 1;         // 再赋值
    std::cout << x << ' ' << y << '\n';  // 10 11
}
```

### 示例 3：读入两个整数并求和

```cpp
#include <iostream>

int main()
{
    std::cout << "Enter two integers: ";
    int a{};
    int b{};
    std::cin >> a >> b;
    std::cout << a << " + " << b << " = " << (a + b) << '\n';
}
```

括号 `(a + b)` 非必须（优先级足够），但有助于可读性。

### 示例 4：花括号拒绝收窄

```cpp
int main()
{
    // int bad{3.14};  // 错误：从 double 到 int 的收窄
    int ok = 3.14;     // 通常合法但截断为 3——更易埋雷
    int better{3};     // 意图清晰
    (void)ok;
    (void)better;
}
```

### 示例 5：展示整数除法

```cpp
#include <iostream>

int main()
{
    std::cout << 5 / 2 << '\n';    // 2
    std::cout << 5.0 / 2 << '\n';  // 2.5（浮点除法）
}
```

## 易错与陷阱

1. **忘记初始化**就使用变量 → UB；局部变量不会自动变 0（与部分其他语言不同）。
2. **混淆 `=` 与初始化语境**：`int x = 1;` 是初始化；单独的 `x = 1;` 是赋值。`==` 才是相等比较（第 6 章）。
3. **`endl` 滥用**：初学可接受，但应理解它带刷新；习惯用 `'\n'`。
4. **字符串与字符**：`"A"` 与 `'A'` 不同；前者是字符串字面量，后者是字符。
5. **输入没有提示**：用户不知道该输入什么；测验程序最好先 `cout` 提示。
6. **把编译错误当运行结果**：缺分号、拼错 `cout` 是编译期问题，程序根本没开始跑。
7. **在头文件里乱写 `using namespace std;`**（本章若暂未分文件也要知道）：后续多文件会污染命名空间，见第 2 章。
8. **整数溢出**：`int` 有范围；超出有符号范围是 UB——类型范围见第 4 章。

## Cherno 视角补充

视频索引见 [Cherno 路线](../cherno/00-roadmap.md)。变量在 Cherno 叙事里首先是**一块有大小的内存**，类型决定占多少字节、如何解释比特；「名字」只是程序员给这块内存贴的标签。

### 用 `sizeof` 建立尺度感

```cpp
#include <iostream>

int main()
{
    std::cout << sizeof(bool) << ' '
              << sizeof(int) << ' '
              << sizeof(double) << '\n';
}
```

不同平台上具体数字可能不同，但习惯问「这个对象有多大」会自然衔接到对齐、缓存行与后面的栈/堆选择。

### 初始化不是客套话

未初始化的局部对象读起来是垃圾比特。Cherno 风格演示常靠调试器看内存窗口；LearnCpp 正文已强调 `{}` 初始化——补充一句工程口径：**能在定义点给确定值，就不要留给「第一次赋值」**。

```cpp
int frameIndex{0};   // 意图：计数从零
int scratch{};       // 零初始化，稍后填
scratch = frameIndex + 1;
```

### I/O 与「真实程序」的距离

`std::cin` / `std::cout` 适合测验与脚手架；游戏/工具里更多是文件、网络、UI。初学仍应练熟流式读写，但要知道：**控制台不是性能路径，也不是唯一输入面**。正文已覆盖花括号拒绝收窄与整数除法——此处不再展开语法表，只提醒：类型选择会在热点路径上变成真实成本。

## 练习指引

- 手写（勿复制）带提示的加法/乘法小程序，练习 `cin`/`cout` 链式写法。
- 故意去掉初始化并在高警告下编译，记录编译器诊断；再对照调试器观察垃圾值（若实现给出）。
- 用 `{}`、`=`、`()` 三种初始化各写一例，并尝试 `int x{1.5};` 看报错。
- 完成第 1 章章末测验：独立实现要求的小程序，重点检查：是否处处初始化、输出格式是否与题目一致、是否误用字符串/字符。
- 预习：把重复逻辑想象成「函数」——引入 [第 2 章](./ch02-functions-files.md)。

## 小结

- 程序由语句构成；变量应**定义时初始化**；I/O 用 `<iostream>`。
- 区分初始化与赋值；优先考虑安全的 `{}` 初始化。
- 读取未初始化对象是典型 UB；警告与良好习惯是第一道防线。
- 字面量、表达式、运算符是后续类型与运算章节的基础积木。
