# 第 21 章：运算符重载

> 来源：[learncpp.cn](https://learncpp.cn/) 第 21 章

## 小节地图

重载原则、友元/普通/成员函数重载、I/O、一元与比较、自增、下标、函数调用运算符、类型转换、赋值、深浅拷贝、与函数模板、项目练习。

## 要点

- 保持直觉：`a + b` 不应有奇怪副作用；优先非成员函数以支持对称转换。
- `operator<<` / `>>` 常作非成员（常为 friend）。
- 赋值运算符注意自赋值与异常安全；资源类考虑三/五法则（并对照第 22 章移动）。
- 下标通常提供 const 与非 const 两个版本。

## 易错点

- 重载 `&&`/`||` 丢失短路（应避免）。
- 类型转换运算符过多导致隐式转换地狱——配合 `explicit`。
- 浅拷贝指针成员造成双重释放。
