## 核心概念

### 运算符、操作数与表达式

运算符（operator）对一个或多个操作数施加运算，得到新值或产生副作用。由运算符、操作数与括号组成的式子称为表达式（expression）。每个完整表达式最终都有一个类型与一个值（`void` 表达式除外）。

### 优先级与结合性

优先级决定「先算谁」：`a + b * c` 等价于 `a + (b * c)`。结合性决定同优先级时的分组方向：绝大多数二元运算符左结合（`a - b - c` → `(a - b) - c`），赋值与条件运算符右结合（`a = b = c` → `a = (b = c)`）。

**实践原则**：不要死记整张优先级表。对可能歧义的表达式一律加括号；团队代码审查中，「能读懂但费劲」的式子应重写。

### 一元、二元、三元

- **一元**：只有一个操作数，如 `+x`、`-x`、`!flag`、`++i`、`~bits`。
- **二元**：两个操作数，如算术、关系、逻辑、赋值。
- **三元**：仅条件运算符 `?:` 有三个操作数。

### 左值与右值（本章所需程度）

赋值左侧必须是可修改的左值（有身份、可寻址的对象）。`++i` 的结果可作为左值使用；`i++` 返回的是旧值的副本（右值），不能写在赋值左侧。更深的值类别见后续引用/移动章节。

### 副作用与求值顺序

副作用指修改对象状态或执行 I/O。自增、赋值、函数调用都会产生副作用。C++17 起对许多运算符的操作数求值顺序做了更严格规定，但**同一对象在一个表达式中被修改两次、或既修改又用于其他目的且无序列点/定序保证时，仍可能是未定义行为或未指明行为**。最安全的规则：**一个表达式里，对同一标量对象最多修改一次，且不要在同一表达式里再读取它作其他用途（自增本身的读写除外）**。

## 语法与 API

### 算术运算符

| 运算符 | 含义 | 备注 |
|--------|------|------|
| `+` `-`（一元） | 正号 / 负号 | `-` 对无符号类型按模运算环绕 |
| `*` `/` `%` | 乘、除、取余 | `%` 要求整型操作数 |
| `+` `-`（二元） | 加、减 | 操作数先按通常算术转换对齐 |

整数除法向零截断（C++11 起明确）：`(-5) / 2 == -2`。取余满足 `(a/b)*b + (a%b) == a`（在 `b != 0` 时）。除零与对 0 取余是未定义行为。

C++ **没有**内建幂运算符。用 `std::pow`（浮点）或整数快速幂自行实现；注意 `std::pow` 返回 `double`，不宜做精确整数幂。

### 自增与自减

```cpp
++x;  // 前缀：先改再取值，结果是左值
x++;  // 后缀：先取旧值副本，再改对象，结果是右值
```

在独立语句中优先写 `++x` / `--x`（意图清晰，对类类型也可能更高效）。循环里 `for (int i = 0; i < n; ++i)` 是惯用法。

### 关系与相等

`<` `<=` `>` `>=` `==` `!=` 的结果类型是 `bool`。链式比较 `a < b < c` **不会**按数学区间理解，而是 `(a < b) < c`，几乎总是逻辑错误。应写 `a < b && b < c`。

浮点相等比较极不可靠：舍入误差会使「理论上相等」的值不相等。比较时应使用误差容限，或改用整数/定点数表达金额等精确量。

### 逻辑运算符

| 运算符 | 含义 | 短路 |
|--------|------|------|
| `!` | 逻辑非 | 无 |
| `&&` | 逻辑与 | 左为假则不求右 |
| `\|\|` | 逻辑或 | 左为真则不求右 |

短路使得 `ptr && ptr->ready()`、`index < size && arr[index] == x` 成为安全惯用法。逻辑运算符的操作数会按语境转换为 `bool`（零为假，非零为真）；对类类型则走 `explicit operator bool` 等转换路径。

注意：按位 `&` `|` `^` **不短路**，且优先级与逻辑运算符不同。日常布尔逻辑务必用 `&&` `||`。位运算详见 [可选笔记](./optional-bit-constexpr.md)。

### 条件运算符 `?:`

```cpp
条件 ? 表达式真分支 : 表达式假分支
```

只求值其中一个分支。两分支的类型须能汇合为一个公共类型。适合简短、两侧对称的取值；复杂逻辑应写成 `if`/`else`，可读性优先。

### 逗号运算符

`,` 从左到右求值，丢弃左侧结果，整个逗号表达式的值与类型取最右侧。优先级极低。在 `for` 的更新子句里偶有用处（`++i, ++j`）；几乎不要在其他地方依赖逗号运算符——函数实参列表里的逗号**不是**逗号运算符。

### 复合赋值

`+=` `-=` `*=` `/=` `%=`（以及位运算复合形式）等价于「右侧运算后再赋回左侧」，但对左侧只求值一次。优先用于更新同一对象：`sum += x;` 优于 `sum = sum + x;`。

## 示例

### 优先级与括号

```cpp
#include <iostream>

int main() {
    int a = 2 + 3 * 4;        // 14
    int b = (2 + 3) * 4;      // 20
    int c = 10 - 3 - 2;       // (10-3)-2 = 5
    bool ok = (a > 10) && (b != c);
    std::cout << a << ' ' << b << ' ' << c << ' ' << ok << '\n';
}
```

### 整数除法与取余

```cpp
#include <iostream>

int main() {
    std::cout << 7 / 2 << '\n';      // 3
    std::cout << 7 % 2 << '\n';      // 1
    std::cout << (-7) / 2 << '\n';   // -3（向零）
    std::cout << (-7) % 2 << '\n';   // -1

    // 判断偶数：优先用位运算或显式比较，注意负数
    int n = -4;
    bool even = (n % 2 == 0);         // true
}
```

### 自增副作用：正确与错误写法

```cpp
#include <iostream>
#include <vector>

int main() {
    int i = 0;
    std::cout << ++i << '\n';  // 1：先增后用
    std::cout << i++ << '\n';  // 1：先用后增；之后 i == 2

    std::vector<int> v{10, 20, 30};
    std::size_t idx = 0;
    int x = v[idx++];          // 取 v[0]，然后 idx 变为 1——常见且清晰

    // 危险：同一表达式对 i 修改两次（不要写）
    // i = i++ + 1;
    // arr[i] = i++;
}
```

### 条件运算符与复合赋值

```cpp
#include <algorithm>
#include <iostream>
#include <string>

std::string label(int score) {
    return score >= 60 ? "pass" : "fail";
}

int main() {
    int lo = 3, hi = 9;
    int mid = lo + (hi - lo) / 2;   // 防溢出写法的整数中点

    int total = 0;
    total += 5;
    total *= 2;                     // 10

    int a = 4, b = 7;
    int m = (a > b) ? a : b;        // 等价于 std::max(a, b)
    std::cout << label(total) << ' ' << m << '\n';
}
```

### 逻辑短路

```cpp
#include <iostream>

bool expensiveCheck() {
    std::cout << "checked\n";
    return true;
}

int main() {
    int* p = nullptr;
    if (p && *p > 0) {              // 不会解引用空指针
        std::cout << "positive\n";
    }

    if (false && expensiveCheck()) {
        // expensiveCheck 不会被调用
    }
    if (true || expensiveCheck()) {
        // 同样不会调用
    }
}
```

### 浮点比较（示意）

```cpp
#include <cmath>
#include <iostream>
#include <limits>

bool nearlyEqual(double a, double b, double absEps = 1e-12) {
    return std::fabs(a - b) <= absEps;
}

int main() {
    double x = 0.1 + 0.2;
    std::cout << std::boolalpha;
    std::cout << (x == 0.3) << '\n';                 // 往往是 false
    std::cout << nearlyEqual(x, 0.3) << '\n';         // true（示例容限）
}
```

## 易错与陷阱

1. **依赖默记优先级**：`a & mask == flag` 实际是 `a & (mask == flag)`，因为 `==` 高于 `&`。布尔与位混合时必须加括号。
2. **数学风格链式比较**：`0 <= x <= 100` 对 `int` 几乎恒为真（`bool` 提升为 0/1 再与 100 比）。
3. **整数除法期望得到小数**：`1 / 2` 是 `0`；需要浮点时写 `1.0 / 2` 或先转换操作数。
4. **`%` 用于浮点**：非法；浮点用 `std::fmod`。
5. **在复杂表达式中混用 `++`/`--`**：结果依赖求值顺序历史包袱；拆成多条语句。
6. **用 `=` 代替 `==`**：`if (x = 0)` 合法但几乎总是 bug；开启 `-Wall` 并考虑把常量写在左侧或使用 `clang-tidy`。
7. **逻辑与按位混淆**：`if (flags & MASK)` 有时正确，但 `if (a && b)` 与 `if (a & b)` 语义不同；后者不短路且对非 0/1 值结果可能出乎意料。
8. **逗号运算符误读**：`f(a, b)` 是两个实参；`f((a, b))` 才是逗号表达式算出一个实参。
9. **条件运算符嵌套过深**：可读性崩溃，改为 `if`/`else` 或查表。
10. **无符号与一元减**：`-u` 在无符号类型上得到很大的正值（模 2^n），不是「负的无符号」。

## 练习指引

- 不查表写出下列表达式的分组，再用括号验证：`a + b << 2`、`x & y == z`、`p || q && r`。
- 手写函数：输入秒数，输出「时:分:秒」（练习 `/` 与 `%`）。
- 把所有含 `i++` 的复合表达式拆成独立语句，确认行为不变。
- 实现 `clamp(v, lo, hi)`，分别用 `if` 与条件运算符各写一版，比较可读性。
- 故意打印 `0.1 + 0.2`，观察为何不等于 `0.3`，并实现带相对/绝对容限的比较函数。

章末测验建议：覆盖优先级改写、整数除法陷阱、短路保护空指针、以及「禁止同一表达式多重修改」四类题。

## 小结

运算符章节的目标不是背诵符号表，而是建立三道防线：**括号消除歧义**、**副作用单独成句**、**布尔用逻辑运算符并依赖短路**。算术要时刻分清整数与浮点语义；比较要警惕浮点与链式写法。掌握这些后，[第 7 章](./ch07-scope-duration-linkage.md) 将进入对象「在哪可见、活多久、跨文件如何共享」的作用域与链接问题。
