# 第 3 章：调试

> 来源：[learncpp.cn](https://learncpp.cn/) 第 3 章

## 小节地图

语法/语义错误、调试流程与策略、打印与断言等战术、IDE：单步、断点、监视、调用栈、事前预防、测验。

## 要点

- **语法错误**编译器拦；**语义错误**要靠测试与调试发现。
- 缩小范围：复现 → 定位 → 假设 → 验证 → 回归。
- 学会：断点、单步进入/跳过、局部变量监视、读调用栈。
- 预防：小函数、高警告、尽早测试边界输入。

## 易错点

- 一次改太多处，无法判断哪次修改生效。
- 只靠“感觉”加 `cout`，不固定复现步骤。
- Release 下才出现的问题（优化/未初始化）却只在 Debug 里猜。
