# 第 7 章：作用域、生命周期与链接

> 来源：[learncpp.cn](https://learncpp.cn/) 第 7 章

## 小节地图

块、用户命名空间、局部/全局变量、遮蔽、内/外链接、为何避免非常量全局、`inline` 函数与变量、跨文件共享常量、静态局部变量、总结、`using`、匿名/内联命名空间。

## 要点

- **作用域**决定名字可见性；**生命周期**决定对象何时存在；**链接**决定跨翻译单元能否共享。
- 非 const 全局变量让推理变难：隐藏依赖、测试困难、数据竞争风险。
- 跨文件常量可用 `constexpr` + `inline`（现代写法）集中定义。
- 静态局部变量：首次经过时初始化，之后保持状态——小心隐藏状态。

## 易错点

- 内层变量遮蔽外层，读错“当前绑的是谁”。
- 头文件里定义非 inline 的全局对象 → 多重定义。
- 头文件 `using namespace` 污染所有包含者。
