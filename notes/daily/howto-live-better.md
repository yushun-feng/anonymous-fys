## 它是什么

开源仓库 **HowToLiveBetter**（中文名「高性价比人生指南」）把几百条「怎么活得更稳」的建议做成可检索清单：寿命、时间精力、金钱、人身自由四类收益，每条写清**花掉什么、换回什么、证据有多硬**，来源优先期刊论文与官方文件。

定位是**备选单**，不是任务清单——挑一两条落地就算数。站内的自律清单偏「节奏与微习惯」；这本书偏「人生重大选择与避坑」，两者互补。

## 怎么用（推荐路径）

1. **先检索，再深读**：打开[在线检索页](https://eternity4719.github.io/HowToLiveBetter/)，按关键词、章节、证据等级，以及「花不花钱 / 花多少时间 / 要不要毅力」筛选；需要时再进对应 `book/0x-….md`。
2. **只想挑硬结论**：勾选证据等级 **A**（有可核数字的荟萃分析 / 大型队列 / RCT 等）。
3. **只想挑省力高收益**：勾选性价比「极高」（不花钱、用时少、少靠毅力，且收益落在最大一档）——适合和站内微习惯一起挑「先做哪几件」。
4. **场景长文**：仓库 `docs/` 里有按时间排的清单（被裁、确诊慢性病、换城市、孩子出生前后等）；比按节翻书更适合「刚出事那一周」。
5. **离线 / 复习**：Release 提供 PDF、EPUB、离线单文件 HTML、Anki 牌组；正文更新后这些产物会自动重生，转发旧文件不会跟着变。
6. **AI 助手**：仓库带 `skills/life-decision-guide`，可让 Claude Code / Codex 先查书里条目再回答，并标明节号条目——仍要以原文与当地规定为准。

## 结构速览（34 节 → 几组）

不必按目录从头读。按「你此刻卡住的问题」进组即可：

| 组 | 大致覆盖 | 典型问题 |
|----|----------|----------|
| **活下去 / 少折寿** | 第 1–2、13、16、20、27–28、34 节等 | 外因与慢性风险、急救顺序、慢性病管理、孕产与婴幼儿、常备药别吃出事 |
| **精力与时间** | 第 3–4、22–23 节 | 睡眠与打断、拖延与无收益项目、放松场所红线、学什么技能划算 |
| **钱与保障** | 第 5–7、15、18–19、24–25 节 | 订阅/保险/利率、没钱时的救助、租买房、育儿账、在职离职工伤、看病少花钱 |
| **法律与红线** | 第 8–9、11–12、14、26 节 | 财产与担保、普通人易踩的坑、程序员红线、创业办证、账号安全、做网站/平台资质 |
| **关系与人生阶段** | 第 10、17、21、29–33 节 | 恋爱结婚、家里有老人、出国旅行、重大打击、上学后的孩子、十八岁后的路、留学与残疾后的活法 |

节标题里的「不要……」说的是**想防住的结果**；真正做或不做，以**条目标题的动词**为准。

## 单条长什么样（读法）

每条大致包含：成本、说人话、收益、证据等级（A/B/C）、来源、备注（争议 / 适用人群等）。

阅读时优先看 **「说人话」** 定主意；要核对再看「收益」栏原始数字与来源链接。注意：

- 百分比多是**相对风险下降**，不是「每一百人少几个」。
- A 级表示「数字可核」，不等于一定是因果；看收益栏是「随机分组」还是「只记录、不分组」。
- 性价比档是作者判断（本身偏 C 级口径），与证据等级独立——证据硬也可能贵、证据软也可能极划算。
